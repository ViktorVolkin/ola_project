# OLA-WF-LEARN-004

Confirmed workflow lessons for the Lead `integration-retrospective` skill.

- A plain `<img>` mock omitted Next Image `fill` positioning; 30 passing mock checks masked 30 real overlap failures. For framework-specific image, routing, or SSR behavior, use an early minimal smoke with the actual framework mount/SSR path. Mocks establish only the simulated layer; do not require a Next app for purely generic unit behavior.
- Repeated worker failures left 42 full source/build exports (5.314 GiB); Markdown was only 1.59 MiB, not the cause. Reuse compatible frozen inputs; set an explicit owner, size budget, and lifetime for disposable test/build outputs; clean them on success, failure, or interruption after preserving small essential evidence. Verify owned ports and remaining allocated bytes. Never broadly delete caches or dependency symlink targets; more free space is not a reason for unbounded retention.
