Excluding the transition would require moving the image up approximately 3.25px or changing its scale; either changes the explicitly mandated reference rectangle. The 1440 reference reaches source row 1103.45, within that transition. The 768 reference reaches row 1072.73, above it.

Local check: Python/Pillow sampled JPEG rows 1080–1124 (316 horizontal samples per row): zero samples had all channels above 235 at y=1105; 99.7% did at y=1107. No CSS or TSX fix was made: exact preservation of all three stated reference rectangles and exclusion of the actual band at every width are mutually incompatible.
