## Deduplicated axe findings: serious impact as assigned by axe, not independently adjudicated severity

1. `label-content-name-mismatch` WCAG 2.5.3, `src/components/widgets/LanguageSwitcher/LanguageSwitcher.tsx`, trigger button `[data-language-open] button`; 75 node occurrences over locales/widths/states including multiple component instances (exact selectors/occurrences in `summary.json`). Example `/en` desktop: visible `EN`, accessible name `Language: English` (real AX snapshot in `raw/desktop-en-home-normal.json`); axe marks mismatch. Reproduce open `/en`, scan with above command. Expected accessible name contains visible label, supporting speech input. Axe is token-sensitive; determine whether locale abbreviations and spoken names satisfy 2.5.3 with assistive technology before selecting a fix. RU/SR variants also flagged. This is an automated finding, not a claim that an accessible name is missing.
2. Same axe rule, `src/components/widgets/Wordmark/Wordmark.tsx`, `header a[aria-label="OLA Floral Studio"]`; 45 case occurrences. Real AX snapshot is link `OLA Floral Studio`, visible text `OLA FLORAL STUDIO`. Automated mismatch may be whitespace/segmentation false positive; do **not** treat as confirmed missing name or product defect without human speech-input review. Example `/en` desktop; selector and full axe data in raw. Underlying owner grouping merges language-switcher instances but preserves each original target and route/state in occurrence list.

`incomplete` is distinct from violations: 307 color-contrast, 27 link-in-text-block and 36 aria-hidden-focus node occurrences, not unique defects; require manual review and are not PASS. Axe cannot establish all WCAG criteria, responsive states, screen reader usability or site certification. Known native 404 raw/no-JS blank behavior lies outside these six normal routes and was not labelled passing. Disabled CTA and recipient hold remain unchanged. No design/Figma access.
