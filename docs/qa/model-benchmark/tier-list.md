# Предварительный тирлист по выполненным мини-тестам

Это практическая оценка текущих маршрутов для коротких coding-задач, а не общий рейтинг моделей. Критерии: правильность и точность требований, следование формату, время до полезного ответа, наблюдаемые блокеры. Без числовых весов и искусственных баллов. Тесты A/B синтетические; по одному ответу на задачу в успешных delegation-прогонах, поэтому уверенность ограничена.

## Практический общий tier

| Tier | Маршрут | Применение по этим наблюдениям |
|---|---|---|
| A — скорость | Gemini 3.5 Flash-Lite | Быстрые небольшие реализации под проверкой тестами. В A распознал оба бага, но неверно указал первые ошибочные строки. |
| A — точность | Kilo Auto Free | Небольшие задачи с точными ограничениями, когда можно подождать. В A выполнил все требования; B прошёл тот же набор проверок. Это router, downstream в последнем запуске неизвестен. |
| Не рекомендован пока в текущей связке | GLM 4.7 Flash | Единственный canary остановлен Hermes из-за повторов после 115,67 с, полезного ответа нет. Это эксплуатационный исход одного запуска, не оценка способности модели в целом. |
| Не оценён | GLM 5.3 Flash | Получены ошибки параметров, затем блокер баланса/пакета HTTP 429. Решений нет; качество и скорость генерации неизвестны. |
| Не оценён | Gemma 4 31B через Google | В предыдущем direct-API прогоне A исчерпал лимит без финального ответа, B вернул HTTP 500. Прямого сопоставимого delegation-прогона нет. |

S-tier не присваивается: слишком мало разных задач и повторов.

## По отдельным критериям

- **Точность выполнения A:** Kilo выше Gemini. Kilo указал строки 3/4 с правильными fixes; Gemini — 2/5, хотя смысл двух проблем распознал.
- **Качество реализации B:** ничья. Оба прошли по 320 независимых случаев плюс 3 теста модели: значения, порядок, неизменность входа, новый массив, лимиты и приоритет удаления.
- **Следование инструкциям на A/B:** Kilo выше Gemini по точности требования о первых ошибочных строках. Чистый JSON в последнем delegation-прогоне соблюли оба на обеих задачах.
- **Измеренная скорость успешных delegation-ответов:** Gemini быстрее в этом прогоне. A/B: Gemini 7,43/6,01 с; Kilo 20,53/12,63 с. Это длительность детей, не изолированная API latency/TTFT. Наследуемые generation settings не раскрыты; неизменность prompt/context подтверждена.
- **Эксплуатационная пригодность сейчас:** Gemini и Kilo дали полезные ответы; GLM 4.7 не завершил canary, GLM 5.3 заблокирован entitlement, Gemma не дала финального решения в прежнем бюджете. Статистическая надёжность не установлена.
- **Цена и экономичность:** рейтинг не строится. Kilo сообщил cost=0 в прежних двух direct-API вызовах; последний delegation-прогон стоимости не раскрыл, для остальных нет сопоставимого измерения. Название Free не является самостоятельным измерением всех будущих затрат.

## Практическое распределение

Gemini — предварительный выбор для скорости на небольших ограниченных задачах с автоматическими тестами; Kilo — кандидат для более точного выполнения узких инструкций и вторичного взгляда на код, но результат всё равно проверять. Ни один из этих тестов не подтверждает качество сложной архитектуры, Figma fidelity, i18n, долгих агентных циклов или изменений всего проекта. Основную модель/маршруты на основании этого отчёта не переключали.
